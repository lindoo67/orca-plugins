# Catppuccin Latte for Orca

A soft pastel light application theme from the Catppuccin Latte palette, with matching terminal colors.

Select **Catppuccin Latte** in Appearance settings for the app and in terminal theme settings
for matching ANSI colors. Includes syntax colors for source files and Markdown.

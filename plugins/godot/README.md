# Godot Syntax

Highlights GDScript (`.gd`), Godot text scenes and resources (`.tscn`, `.tres`, `.escn`), project settings and metadata (`.godot`, `.import`, `.remap`, `.gdextension`), and shaders (`.gdshader`, `.gdshaderinc`).

The GDScript and resource grammars are from the MIT-licensed [Godot VS Code plugin](https://github.com/godotengine/godot-vscode-plugin), vendored from [Orca PR #20454](https://github.com/stablyai/orca/pull/20454) at commit `079777ea0df7782b3c6ea80c7cb2a43590efe3cd`. The shader grammar is from the same upstream project at `145a0f0ad5a6c726b27b18b517c217a5e1bfa91c`. Its license is included.

# Gruvbox for Orca

Retro warm dark and light application themes, with matching Gruvbox terminal colors.

Select **Gruvbox Dark**, **Gruvbox Light** in Appearance and terminal settings.

## Attribution

An unofficial Orca port of [Gruvbox](https://github.com/ellisonleao/gruvbox.nvim).
The app mapping and syntax scopes are maintained here. Low-contrast syntax shades
are adjusted to pass Orca’s runtime checks; terminal ANSI colors use the upstream palette.

# LaTeX Syntax

Highlights `.tex`, `.ltx`, and `.sty` files. The LaTeX and TeX TextMate grammars are from Shiki's `@shikijs/langs` 4.5.0, derived from [VS Code's MIT-licensed grammars](https://github.com/microsoft/vscode/tree/main/extensions/latex). The TeX grammar is included as a dependency. Embedded languages whose grammars are not included may remain plain.

# OCaml Syntax

Highlights OCaml implementations (`.ml`), interfaces (`.mli`) and [MLX](https://github.com/ocaml-mlx/mlx) files (`.mlx`), including ocamldoc comments.

Orca opens `.ml` and `.mli` files as F# by default. From Orca 1.4.246, an enabled plugin syntax takes precedence, so while this plugin is on those files are highlighted as OCaml. Older Orca versions show "Needs Orca 1.4.246".

The TextMate grammars are from the ISC-licensed [OCaml Platform for VS Code](https://github.com/ocamllabs/vscode-ocaml-platform) at commit `c8862c716bc9d148792d3edf19b111a087f87624`.

# QML Syntax

Highlights Qt QML files (`.qml`) and QML module definition files (`qmldir`): imports, object types, properties, signals, and the JavaScript in bindings and signal handlers.

The QML and qmldir TextMate grammars are from the MIT-licensed [seanwu1105/vscode-qt-for-python](https://github.com/seanwu1105/vscode-qt-for-python) at commit `11171174a0f94d3cb6ad818ce15ada8589b1f87d`, unchanged; their license is in `syntaxes/qml-LICENSE.txt`. The JavaScript grammar, included only for the code inside QML, is from the MIT-licensed [microsoft/vscode](https://github.com/microsoft/vscode/tree/main/extensions/javascript) at commit `03ac83a153c2ecc09362459fc7a706674620e257`, unchanged; its license is in `syntaxes/javascript-LICENSE.txt`.

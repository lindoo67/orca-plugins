# Taxi Timesheets Syntax

Highlights [Taxi](https://github.com/sephii/taxi) timesheet files (`.tks`): project aliases, durations, descriptions and comments. The TextMate grammar is from the MIT-licensed [LeBenLeBen/taxi-syntax-highlighting](https://github.com/LeBenLeBen/taxi-syntax-highlighting) at commit `3df8cbceec3c917b4930946e4f0ba73939906882`, unchanged. Its license is in `syntaxes/taxi-LICENSE.txt`.

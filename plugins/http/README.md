# HTTP Request Files

Highlights `.http` and `.rest` request files, as used by REST Client and JetBrains HTTP Client: request lines, headers, variables, comments and `###` separators. JSON request bodies are highlighted too.

The HTTP grammar is from the MIT-licensed [Huachao/vscode-restclient](https://github.com/Huachao/vscode-restclient) at commit `0773d56b65d9e7033259519e99eef8f752f6ba6e`, unchanged; its license is in `syntaxes/http-LICENSE.txt`. The JSON grammar, included only for request bodies, is from the MIT-licensed [microsoft/vscode](https://github.com/microsoft/vscode/tree/main/extensions/json) at commit `03ac83a153c2ecc09362459fc7a706674620e257`, unchanged; its license is in `syntaxes/json-LICENSE.txt`. XML, GraphQL and curl bodies stay plain.

# Dracula for Orca

A dark application theme with Dracula’s vivid pink, purple, and green palette, plus matching terminal colors.

Select **Dracula** in Appearance and terminal settings.

## Attribution

An unofficial Orca port of [Dracula](https://draculatheme.com/).
The app mapping and syntax scopes are maintained here. Low-contrast syntax shades
are adjusted to pass Orca’s runtime checks; terminal ANSI colors use the upstream palette.

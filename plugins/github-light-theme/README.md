# GitHub Light for Orca

A crisp white application theme inspired by GitHub's default light palette, with matching terminal colors.

Select **GitHub Light** in Appearance settings for the app and in terminal theme settings
for matching ANSI colors. Includes syntax colors for source files and Markdown.

Secondary controls use a deeper cool gray (`#d8dee4`) so buttons such as **AI Fix**
remain visible on the light gray cards, muted surfaces, and sidebar (`#f6f8fa`),
including their translucent hover state. The secondary foreground stays `#1f2328`.
Muted text uses `#57606a` to keep at least 4.5:1 contrast on secondary surfaces too,
such as inline badges.

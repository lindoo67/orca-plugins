# GitHub Light for Orca

A crisp white application theme inspired by GitHub's default light palette, with matching terminal colors.

Select **GitHub Light** in Appearance settings for the app and in terminal theme settings
for matching ANSI colors. Includes syntax colors for source files and Markdown.
